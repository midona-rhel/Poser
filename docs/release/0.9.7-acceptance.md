# 0.9.7 acceptance

Accepted by the user on 2026-09-06; deployed candidate `98df10a3`.

- World borrowing, replacement readiness and cleanup changes were accepted.
- Character-file import was accepted, including the library entry point without
  an additional automated UI test. The user confirmed persistence after restart.
- Live checks covered authored actor transforms/appearance and C+ through repeated
  lifecycle undo/redo, plain copies and copies of copies, light/camera duplication,
  an additive mixed-scene load with undo/redo, and MCDF import/reset.
- The mixed-scene fixture did not include embedded MCDFs, groups, scenery or VFX;
  those combinations are not claimed as measured by that particular test.
- GPose exit removed test copies and temporary integrations; fresh entry had no
  test lights/cameras or history. The original saved C+ profile remained active.
- Header choices and detached inspector geometry survived the tested transitions.
- Animation playback is intentionally not reconstructed by lifecycle history;
  authored bone transforms are restored instead.

Known follow-up: [#196](https://github.com/midona-rhel/Poser/issues/196), stale
nicknames on reused actor slots after GPose re-entry, explicitly separated by
the user from this acceptance.

A later native renderer crash occurred outside GPose after appearance/mod changes.
The log contained failed material loads; the exact cause was not established.
The user reviewed that diagnosis and explicitly authorized this merge/release.

Release compilation, tests, package verification and dependency audit are run on
the exact release-branch head; publication evidence is carried in its assets.
