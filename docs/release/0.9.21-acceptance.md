# 0.9.21 release authorization and coverage

The user authorized the release on 2026-10-18 ("review merge and when ready new
release"), after the pull requests for it were reviewed and their review threads
answered.
Accepted main base: `ff7aa5651bcaa4cddf3ed1d29d3be278cca12ba2` (squash merges of
#591, #592, #593, #594, #595, #596, #597 and #598).
Accepted live runtime: `cf37f98a`, which is that code before the review fixes
listed below, plus the Debug probe routes.

- No open issue tracks these fixes; none is closed by this release. #535 stays
  open for its other GPose features.
- Start GPose without depth of field, live: entering GPose with the setting on
  left depth of field off, confirmed by the user. Not tested: the idle camera.
- Driven bones (#591), live on a clone: a ×1.2 scale edit on a translate-driven
  eye bone lands as exactly ×1.2 with the setting on and off. Not tested: a
  scale-driven child bone (needs gear or hair with a scale driver).
- Body colliders, live: generation forms its group as one "Create body
  colliders" step; undo and redo work. The waist seam closes the crease: at the
  seam height the belly and back are covered ±8 cm (±4 cm before).
- Rope with collisions, live on a Wind-up Titan leash with body colliders:
  turning collisions off and on and changing Parent depth leave the chain end in
  place (it jumped 1.78 m before).
- Sidebar, live: clicking Body keeps the row selected; Spine lists Waist.
- Borrowed actors, live on a borrowed map NPC (object index 501): hide, show,
  hide then release, and hide then leaving GPose all leave it as expected.

Review fixes after the live runtime, checked in game after publishing on the
release code (`d8ef7502`, main plus the Debug probe routes):

- The Waist row: hovering it with Lumbar selected leaves the Spine header
  unhighlighted; clicking it, and clicking the Spine header, both select the
  waist and light both rows.
- Borrowed actors: Opacity 0.3, then hide, gives alpha 0; show gives 0.3 back;
  hiding again and then releasing, or hiding and then leaving GPose, leaves the
  borrowed NPC at the world's alpha 1 when it is borrowed again.
- Collider generation abort: with a collider group in the scene, a pending
  generation aborted after GPose exit leaves no group. With the previous abort
  the old group came back after the exit; that run is the control.
- The waist seam on a real body (capsule slices) is still generated and covers
  the crease. The round (sphere) case is covered by its unit test only.

Build, tests, archive verification, vulnerability audit and SBOM are performed
against the exact release head. Release validation does not deploy Debug.
