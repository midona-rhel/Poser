# 0.9.24 release authorization and coverage



Midona authorized the release on 2026-11-08: "yes, and build a new release".

Accepted main base: `565f4702da3d381027690607aaf08b5f14366e45` (PR #697).

Accepted live runtime: `bd85ae40`.



The integration includes the accepted changes from #664, #683 and #686, plus

the scene, MCDF, IK, camera, Library and placement corrections tested afterwards.

PR #697 lists the completed issues. The whole-app audit and its unfinished work

packages remain open.



- The Release build and all 906 existing tests passed on the integration tree.

- Live scene and MCDF checks covered character matching, anonymous saves,

  pose preservation and reusing borrowed map objects.

- IK checks covered target switches, undo, baking one chain, and pose exports.

- Camera checks covered saved positions, autosave cameras and the active view.

- Midona accepted the Library resize fix.

- The final placement consolidation passed 28 live checks, including new entities,

  posed copies, group spacing and creation undo/redo. Its runtime DLL hashes matched.

- Release review also corrected Library entries reusing the original actor and scene undo leaving reused actors changed. Live checks passed for spawning a copy, matching on scene load, and undo restoring the original position.
- Earlier audit checks and their limits are linked from the validation records.

  This release does not claim exhaustive coverage of every race, mod or animation.

- The first placement implementation missed new lights before their scene IDs

  existed. The shared object-based transform path corrected it; the repeat passed.

- An initial orbit-camera reading differed during a previous camera-switch sequence.

  Three earlier repeats and the final placement run passed; its original cause

  was not established. No specific fix for that single reading is claimed.
