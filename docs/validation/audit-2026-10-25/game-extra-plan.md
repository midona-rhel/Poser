# Scene and world-object source audit

Head: `04b09fd7272de82035c207e51e13a428595612bd`. All 37 assigned files were read in full; `game-extra.csv` records the individual evidence. This patch changes comments only. These are proposed runtime followups, not implemented fixes.

1. **Validate native identity before every deferred BG write.** `WorldObjectService.OnFrameworkUpdate` retries stains using `IsAlive`, then writes pending night state, animation speed, and held night state before its later VFX identity check. `AdoptedWorldObject.AnimationPaused` also reaches `WriteAnimationPaused`, which checks address liveness rather than `IsHandleCurrent`. Reuse the existing identity guard before these writes; retire or retain pending work deliberately when identity changes. Extend `WorldObjectRestoreTests` with a replacement allocation at the same address and assert no deferred writes reach it. This is separate from the post-render hold: `SceneFramePhaseService` binds `objects.HoldPausedAnimations` through its `_anchor` delegate, and that path already checks identity.

2. **Bound graph collection as well as processing.** `WorldService.RefreshCore` reaches `WorldObjectService.GetCandidates/GetEffectCandidates`, and `WorldLightCapture` reaches `EnumerateLights`; both reach `WorldGraphWalker.Walk`. Its outer loop checks `MaxNodes`, but `PushRing` can add an arbitrarily long sibling chain before returning. Apply the budget inside sibling collection, carry an explicit incomplete-walk result, and continue skipping identity pruning after truncation. Test oversized rings, repeated nodes, and nested children. Consider one shared discovery snapshot per refresh only after measuring the separate object/effect/light walks.

3. **Validate AVFX chunk bounds before pointer access.** `VfxResourceLoadDetour` passes a real buffer length to `UnbindAllTimelineItems`, but that method trusts the root chunk's declared payload length. `FindChunk` also rounds unsigned payload lengths and converts them to signed offsets without validating overflow or forward progress. Introduce a bounded span-based chunk reader used by both timeline walks. Test oversized root lengths, truncated headers, overflowing lengths, and valid nested `BdNo` writes. Keep the native hook and claim checks unchanged while replacing parsing.

4. **Give appearance temporaries explicit process ownership.** `SceneAppearanceRuntime` starts `SessionAppearanceFiles.DeleteStale` against shared temp directories. The one-day age test does not protect a package still retained by another long-running client. First confirm concurrent clients use the same directories and can retain a package past the cleanup age. If confirmed, choose per-process/session directories or an existing ownership check before cleanup; do not add liveness-marker machinery without that evidence. Extend `SessionAppearanceFilesTests` beyond young-versus-old files to cover old files still owned by a live client. Keep successful imported packages readable until their owning history session ends.

5. **Preserve allocation identity through initial world spawn failure.** `WorldObjectService.Spawn` calls the address-only `_port.Spawn` overload, unlike `WorldObjectRespawner.Respawn`, which retains the allocation identity returned by the three-argument overload. `NativeWorldObjectPort.Spawn` can return zero after an allocation or placement failure while its identity remains available. Route initial creation through that overload and the existing exact-incarnation cleanup/retry mechanism. Inject post-allocation failure and failed identity reads in a fake port; verify eventual cleanup without deleting a replacement allocation.

6. **Remove obsolete helpers after checking compatibility expectations.** Repository C# search finds no call to private `ActorServiceLifecycle.CapturePose`; copying now uses `CapturePoseForCopy` and `ReadCopyState`, while scene save uses `SceneCaptureService.BeginCapture` through `SceneAppearanceRuntime.ArmSceneCapture` and composition's capture callback. Remove the private dead capture method in a later code patch. `WorldObjectService.IdentityToleranceYalms` likewise has no C# caller; current reclaim uses graph membership plus `MatchesBorrowedIdentity`. Decide whether the public constant needs a compatibility period before removing it.
