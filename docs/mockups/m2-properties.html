TAB MODEL: the tab set is a pure function of the selection TYPE (actor: Pose/Animation/Appearance · bone: Pose · camera: Camera · light: Light), followed by the always-present scene tabs (Environment/Library) after a divider. The sidebar is the only list of entities — panes never repeat it. Pose — three tabbed views (Body / Face / Bones, per the Anamnesis reference; matrix transcribed from PoseMatrixView.xaml, dynamic auto-fit columns, multi-select pills + Clear selection). Gizmo mode/space appears ONCE, in the titlebar; a popped-out Pose window grows its own copy. Inspector rail = rotation ball (free-rotate sphere, per-axis rings) + rotation/position/scale scrubbers + IK, like Brio’s bone widget.

Animation — emote search feeds the Base slot; the four slots map to XIV's animation layers (Base / Upper body / Facial / Lips). Scrub freezes a frame to pose on top of.

Appearance — DELEGATED to Glamourer (user decision 2026-07-16): no native gear/customize editor. Quick design apply/revert + primary "Open in Glamourer" (targets selected actor), Customize+ profile, redraw. Everything else lives in Glamourer itself.

Camera — selecting a camera in the SIDEBAR (the one and only camera list) shows that camera's properties: lens sliders, collision/delimit behaviors, portrait-mode handoff. Tabs are typed by selection: a camera offers only its Camera tab + the scene tabs.

Light — the sidebar LIGHTS group is the list; selecting a light edits it directly: color swatches, intensity/range/falloff, shadow toggle. (3-light game cap — Ktisis lifts it; under investigation.)
