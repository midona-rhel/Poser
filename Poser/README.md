# Poser

The Dalamud plugin host project: entry point, composition root, configuration, and the UI windows and panes. It is one project of several — the posing runtime, the game interop, the domain model and the widget library are their own projects beside it.

Start at the repository root [README.md](../README.md) for what Poser is, the attribution it owes Anamnesis, Ktisis and Brio, and its license. How to contribute is in [CONTRIBUTING.md](../CONTRIBUTING.md), and the rules for writing are in [AGENTS.md](../AGENTS.md); the documentation set is under [docs/](../docs/).
