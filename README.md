# Poser

Poser is a beta [Dalamud](https://github.com/goatcorp/Dalamud) plugin for
posing actors and building scenes in FINAL FANTASY XIV's group pose mode.

## Features

- Pose actors and bones with overlay handles, a body map, numeric controls,
  multi-selection, gizmos, IK, mirror, flip, reset, stash, undo, and redo.
- Play, loop, speed up, slow down, and scrub animations; set expressions and
  gaze; freeze physics.
- Build scenes with actors, objects, lights, cameras, environment, borrowed
  world objects, and overlays; save and load the whole scene.
- Change models, opacity, tint, and wetness; use supported Penumbra,
  Glamourer, Customize+, and MCDF integrations.
- Keep pose and scene libraries with tags, search, and previews; use autosave,
  reference pictures, and rebindable shortcuts.

See the [release notes](docs/release/CHANGELOG.md) and the
[documentation](docs/).
